4.3. Output files¶

This section explains the output files generated by \({\mathcal H}\Phi\).

4.3.1. Quick Reference¶

Check and Validation Files

File

Description

CHECK_Chemi.dat

Chemical potential terms

CHECK_InterAll.dat

General two-body interactions

On-site Coulomb interactions

CHECK_Hund.dat

Hund coupling terms

CHECK_INTER_Sr.dat

Inter-site interactions

CHECK_Memory.dat

Memory usage estimation

WarningOnTransfer.dat

Warnings about transfer integrals

File

Description

4.3.2. Detailed Specifications¶

Check and Validation Files¶

These files are generated to verify the input and check memory requirements.

  • CHECK_Chemi.dat
  • CHECK_InterAll.dat
  • CHECK_CoulombIntra.dat
  • CHECK_Hund.dat
  • CHECK_INTER_U.dat
  • CHECK_Memory.dat
  • WarningOnTransfer.dat

Timing and Progress Files¶

These files track the calculation progress and timing.

  • CalcTimer.dat
  • TimeKeeper.dat
  • sz_TimeKeeper.dat
  • Time_CG_EigenVector.dat

Lanczos Method Output¶

Output files specific to Lanczos calculations.

  • energy.dat
  • Lanczos_Step.dat

TPQ (Finite Temperature) Output¶

Output files for thermal pure quantum (TPQ) state calculations.

  • Time_TPQ_Step.dat
  • Norm_rand.dat
  • SS_rand.dat
  • Flct_rand.dat

Time Evolution Output¶

Output files for time evolution calculations.

  • Time_TE_Step.dat
  • Norm.dat
  • SS.dat
  • Flct.dat

Physical Quantities¶

Files containing calculated physical quantities.

  • Eigenvalue.dat
  • phys.dat
  • cisajs.dat
  • cisajscktalt.dat

Wave Functions and Vectors¶

Files containing wave function and vector data.

  • ham.dat
  • eigenvec.dat
  • tmpvec.dat
  • recalcvec.dat
  • eigenvec.dat

Dynamical Green’s Functions¶

Output files for dynamical Green’s function calculations.

  • DynamicalGreen.dat
  • TMcomponents.dat
  • residual.dat
