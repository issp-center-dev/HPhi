Collectively build a representative owner map.

rank_offsets[0..nrank] and local_basis remain caller-owned. The directory owns a local representative index and one first-key splitter per nonempty rank. With active MPI, rank/nrank must match MPI_COMM_WORLD. Without active MPI, only rank 0 of a one-rank layout is valid. directory_out must point to NULL and is updated only after collective success.
