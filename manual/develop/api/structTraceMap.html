Detailed Description

Precomputed basis mapping k -> (k', amplitude) for one GF operator.

n == X->Check.idim_max (the process-local Hilbert dimension, canonical or grand-canonical). kprime[k] in [-1, n-1]: 0-based destination for source basis state k (0-based; vector slot k+1), or -1 if O annihilates it. amp[k] is meaningful only where kprime[k] >= 0. is_diagonal is a hint (kprime[k]==k wherever it survives).

Sentinel: n == 0 with kprime == amp == NULL means "this operator pair is irregular (Rearray_Interactions rejected it): the Mode-1 path writes a 0.0 row for it". A regular operator that merely happens to annihilate every state instead has n == idim_max with every kprime == -1 (also streams to 0).
