int Multiply ( struct BindStruct *  X)

Function of calculating the i-th step norm as.

\[ N^{(i)} = |L v_1^{(i)}-v_0^{(i)}/N_s | \]

and update the i+1-th wave vector as

\[ v_0^{(i+1)} = \frac{L v_1^{(i)}-v_0^{(i)}/N_s}{N^{(i)}} \]

for TPQ calculation
