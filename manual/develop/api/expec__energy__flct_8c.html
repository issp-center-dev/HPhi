Detailed Description

Compute energy expectation value and energy fluctuation (variance)

Calculates:

  • Energy: E = <psi|H|psi>
  • Energy squared: E2 = <psi|H^2|psi>
  • Variance: Var(E) = E2 - E^2 (measures eigenstate quality)

A small variance indicates the state is close to an eigenstate. For exact eigenstates, Var(E) = 0.

Mode:

  • Sets X->Large.mode = M_ENERGY
  • Full H|psi> computation followed by inner product

int expec_energy_flct ( struct BindStruct *  X)

Calculate energy expectation value and variance.

Computes E = <psi|H|psi> and E2 = <psi|H^2|psi> to obtain energy and its fluctuation. The variance Var(E) = E2 - E^2 serves as an accuracy measure: smaller variance means better approximation to eigenstate.

Calculation method:

  1. Compute v0 = H*v1 using mltply()
  2. E = <v1|v0> = <psi|H|psi>
  3. E2 = <v0|v0> = <H*psi|H*psi> = <psi|H^2|psi>
  4. Var = E2 - E^2

Results stored in:

  • X->Phys.energy: Energy expectation value
  • X->Phys.var: Energy variance

XStruct containing physical quantities [in,out]
Returns
0 on success, -1 on error
