Detailed Description

Compute one-body Green's functions \(\langle\psi| c^\dagger_i c_j |\psi\rangle\).

Calculates expectation values of fermion bilinear operators for the given eigenvector. Results are written to output files (zvo_cisajs*.dat).

Operator types by model:

  • Hubbard/HubbardGC: \(\langle c^\dagger_{i,\sigma} c_{j,\sigma}\rangle\) (hopping correlation)
  • Spin/SpinGC: \(\langle S^+_i S^-_j\rangle\), \(\langle S^z_i\rangle\) (spin correlation/magnetization)
  • SpinlessFermion: \(\langle c^\dagger_i c_j\rangle\) (spinless hopping)

Naming convention:

  • "cisajs" = c†_{i,s} c_{j,s} where c = creation/annihilation, i,j = sites, s = spin

Compute one-body Green's functions \(\langle\psi| c^\dagger_{i,s} c_{j,s} |\psi\rangle\).

Main entry point for one-body correlation function calculation. Iterates over all operator pairs defined in X->Def.CisAjt and computes their expectation values.

Mode:

  • Sets X->Large.mode = M_CORR (correlation function mode)
  • No wavefunction update, only expectation values computed

Output:

  • Results written to zvo_cisajs_*.dat files
  • Format: i sigma j sigma Re(correlation) Im(correlation)
Parameters
XStruct with operator definitions in X->Def.CisAjt [in]
vecEigenvector to compute expectation values for [in]
Returns
0 on success, -1 on error
