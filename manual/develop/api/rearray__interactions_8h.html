Detailed Description

Canonical declaration of Rearray_Interactions() – the two-body Green's-function operator reordering shared by the Mode-1 expec dispatch (src/expec_cisajscktaltdc.c), the ExpecMode-2 mapping extraction (src/expec_trace.c), and the trace-map unit test (test/unit/expec_trace_map_check.c, which links the real definition).

The definition lives in src/rearray_interactions.c (moved verbatim out of src/expec_cisajscktaltdc.c in phase 3b Task 2 so the unit test can link the REAL function instead of a drift-prone copy). It reads only X->Def.{CisAjtCkuAlvDC,TBody,FBody,SBody} and performs no MPI.
