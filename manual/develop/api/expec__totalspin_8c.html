Detailed Description

Compute total spin expectation values \(\langle S^2 \rangle\) and \(\langle S_z \rangle\).

Calculates:

  • \(\langle S^2 \rangle = \langle\psi|S_{\rm total}^2|\psi\rangle\) where \(S_{\rm total} = \sum_i S_i\)
  • \(\langle S_z \rangle = \langle\psi|S_{z,\rm total}|\psi\rangle\)

The total spin S^2 can be expressed as: S^2 = Sz^2 + (S+S- + S-S+)/2 = sum_i Sz_i^2 + sum_{i!=j} Sz_i Sz_j

  • (1/2) sum_{i!=j} (S+_i S-_j + S-_i S+_j)

For spin-1/2: S^2 eigenvalue is S(S+1) where S = 0, 1/2, 1, 3/2, ... Good quantum number in Hubbard model (but not SpinGC due to pair creation)

Model dispatch:

  • Spin/SpinGC: Direct spin operator calculation
  • Hubbard/Kondo: Map to spin operators via n_up - n_down

)

Calculate total spin \(\langle S^2 \rangle\) and \(\langle S_z \rangle\).

Dispatches to model-specific implementations:

  • Spin: totalspin_Spin (uses fixed Sz from input)
  • SpinGC: totalspin_SpinGC (Sz not conserved)
  • Hubbard/Kondo: totalspin_Hubbard (maps to spin via fermion operators)
  • HubbardGC: totalspin_HubbardGC

Results stored in:

  • X->Phys.s2: Total spin \(\langle S^2 \rangle\)
  • X->Phys.Sz: Total Sz \(\langle S_z \rangle\)

Mode:

  • Sets X->Large.mode = M_TOTALS

0 (always succeeds)
