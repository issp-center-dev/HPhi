A main function to calculate spectrum by BiCG method In this function, the \(K\omega\) library is used. The detailed procedure is written in the document of \(K\omega\). https://issp-center-dev.github.io/Komega/library/en/_build/html/komega_workflow_en.html#the-schematic-workflow-of-shifted-bicg-library.

Return values
0normally finished
-1error
Author
Mitsuaki Kawamura (The University of Tokyo)

  • Malloc vector for old residual vector ( \({\bf r}_{\rm old}\)) and old shadow residual vector ( \({\bf {\tilde r}}_{\rm old}\)).

  • Set initial result vector(+shadow result vector) Read residual vectors if restart

  • Input \(\alpha, \beta\), projected residual, or start from scratch

  • DO BiCG loop
    502

  • \({\bf v}_{2}={\hat H}{\bf v}_{12}, {\bf v}_{4}={\hat H}{\bf v}_{14}\), where \({\bf v}_{12}, {\bf v}_{14}\) are old (shadow) residual vector.

  • Update projected result vector dcSpectrum (all nBra spectra at once).

  • Output residuals at each frequency for some analysis. Keep the historical 10-step cadence, and add the first spike/final iteration so rare failures carry the decisive per-frequency values without making large production spectrum runs write Lanczos_max*Nomega lines.

END DO BiCG loop

Save \(\alpha, \beta\), projected residual

output vectors for recalculation

Parameters
[in,out]X
[in]vrhs[CheckList::idim_max] Right hand side vector, excited (ket) state A|phi>.
[in]vlhs_Bra[nBra][CheckList::idim_max] Left (bra) states B_b|phi>, projection <B_b phi|r>. Pass {vrhs} for the diagonal G_AA.
[in]nBraNumber of left (bra) vectors. One BiCG solve yields the spectrum for every bra (Komega nl projections).
[in,out]v2[CheckList::idim_max] Work space for residual vector \({\bf r}\)
[in,out]v4[CheckList::idim_max] Work space for shadow residual vector \({\bf {\tilde r}}\)
[in]NomegaNumber of Frequencies
[out]dcSpectrum[nBra*Nomega] Spectrum, Fortran layout x(nBra, Nomega): dcSpectrum[iomega*nBra + ibra]
[in]dcomega[Nomega] Frequency
