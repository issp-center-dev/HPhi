Coding rule

General Rules

  • Do not use TAB character. Use two spaces as an indent.
  • Use C99 standard for compatibility.
  • All source files should include the GPL license header.
  • Use Doxygen-style comments for all public functions.

Naming Conventions

Function Names

  • Use CamelCase with descriptive prefixes:
    • child_ : Internal functions called by main routines
    • X_child_ : Internal functions with explicit struct parameter
    • _GetInfo : Functions that retrieve information
    • _MPI : MPI-specific implementations
    • _MPIsingle / _MPIdouble : Single/double MPI communication patterns

Example: X_child_GC_general_hopp_MPIsingle()

Variable Names

  • Loop indices: i, j, idim, jdim
  • Site indices: isite1, isite2
  • Spin indices: sigma1, sigma2, ispin
  • Bit representations: ibit, ibitsite
  • Temporary values: tmp_v0, tmp_v1, tmp_trans
  • Damping/product: dam_pr (Hamiltonian matrix element)

Macro Names

  • Use ALL_CAPS with D_ prefix for constants:
    • D_FileNameMax
    • D_CharTmpReadDef
  • Model types: Hubbard, Spin, HubbardGC, SpinGC, etc.
  • Calculation types: Lanczos, TPQCalc, FullDiag, CG

OpenMP Parallelization

  • Always use default(none) for scoping of OpenMP-parallel region:
    #pragma omp parallel for default(none) private(idim) shared(wave,i_max,ie)
    for (idim = 1; idim <= i_max; idim++) wave[ie][idim] = 0.0;
  • Classify all variables explicitly:
    • private() : Thread-local variables (loop indices)
    • shared() : Read-only shared data, const variables
    • firstprivate() : Variables initialized from master thread
    • reduction() : Variables for accumulation (+, *, max, min)
  • Variable declared with const must not be included in firstprivate. Use shared instead.
  • Use conditional compilation for OpenMP headers:
    #ifdef _OPENMP
    #include <omp.h>
    #endif

MPI Parallelization

For MPI parallelization, use the following wrapper functions:

  • fgetsMPI() instead of fgets
  • fprintf(stdoutMPI,... instead of printf(...
  • fopenMPI() instead of fopen
  • exitMPI() instead of exit

Additional MPI utilities in wrapperMPI.h:

  • MaxMPI_li(), MaxMPI_d() : Get maximum across processes
  • SumMPI_li(), SumMPI_dc() : Sum across processes
  • NormMPI_dc() : Compute vector norm
  • VecProdMPI() : Compute vector inner product

Use conditional compilation for MPI-specific code:

#ifdef MPI
// MPI-specific implementation
#endif

Memory Management

  • Use dedicated allocation functions from setmemory.c:
    • i_1d_allocate(), i_2d_allocate() : int arrays
    • d_1d_allocate(), d_2d_allocate() : double arrays
    • cd_1d_allocate(), cd_2d_allocate() : complex double arrays
    • lui_1d_allocate() : unsigned long int arrays
  • Always use calloc (not malloc) for automatic zero-initialization.
  • Check allocation results for critical allocations.

Error Handling

  • Return int for error codes: 0 = success, -1 = error
  • Use global error messages defined in ErrorMessage.h/c
  • Always check file operations:
    fp = fopenMPI(filename, "r");
    if (fp == NULL) {
    fprintf(stdoutMPI, cErrFIOpen, filename);
    return -1;
    }

Testing

When you add new features into HPhi, please run:

make test

and check whether other features still work fine. Also, try MPI tests:

make test MPIRUN="mpiexec -np 4"
