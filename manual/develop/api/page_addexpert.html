Add new input-file for Expert mode

Overview

Expert mode input files are processed in readdef.c. Each input file type is registered in the file list (namelist.def).

Steps to Add New Input File

Step 1: Define Keywords

Add keywords to DefCommon.h:

#define KWMyNewFile 100 // Unique keyword ID

Step 2: Add File Type

In readdef.c, add to cKWListOfFileNameList[]:

cKWListOfFileNameList[KWMyNewFile] = "mynewfile";

Step 3: Implement Reader

File Format Guidelines

  • First line: Number of entries (header)
  • Comment lines start with #
  • Use space or tab as delimiters
  • Indices are 0-based
