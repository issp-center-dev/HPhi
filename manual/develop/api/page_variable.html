Global Variables

Global variables are defined in global.h and global.c.

MPI-related Variables

  • nproc : Total number of MPI processes
  • myrank : Rank of current MPI process
  • nthreads : Number of OpenMP threads
  • stdoutMPI : MPI-safe stdout (only rank 0 writes)

Path and File Variables

  • cParentOutputFolder : Output directory path ("output/")
  • cFileNameTimeKeep : Timer log filename

Wavefunction Vectors

  • v0, v1 : Main wavefunction vectors
  • v1buf : MPI communication buffer
  • list_1 : Hilbert space basis list
  • list_2_1, list_2_2 : Two-body basis lists

DefineList (X->Def)

Contains all input parameters:

  • Nsite : Number of sites
  • Ne, NeMPI : Number of electrons (local/total)
  • Nup, Ndown : Number of up/down spins
  • iCalcType : Calculation method (Lanczos, TPQ, etc.)
  • iCalcModel : Model type (Hubbard, Spin, etc.)
  • NTransfer : Number of transfer terms
  • NInterAll : Number of interaction terms
  • GeneralTransfer[][] : Transfer integral indices
  • ParaGeneralTransfer[] : Transfer integral values

LargeList (X->Large)

Temporary data for Hamiltonian operations:

  • prdct : Inner product accumulator
  • is1_spin, is2_spin : Spin masks
  • isA_spin, isB_spin : Additional spin masks
  • tmp_trans : Current transfer value
  • mode : Operation mode flag

PhysList (X->Phys)

Physical quantities:

  • energy : Ground state energy
  • var : Energy variance
  • doublon : Double occupancy
  • num : Particle number
  • Sz : Total \(S_z\)
  • s2 : Total \(S^2\)
