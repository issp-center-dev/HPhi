Add new parameter into modpara

Overview

ModPara file contains calculation parameters. Parameters are read in readdef.c function ReadModPara().

Steps to Add New Parameter

Step 1: Add to DefineList

In struct.h, add new member to DefineList:

struct DefineList {
// ... existing members ...
int MyNewParam; // Description of new parameter
};

You can set a value of parameters with a new keyword in modpara file by following way.

  • Define a new variable corresponding to the above parameter in struct.h file.

  • The value with the keyword are read by ReadDefFileNInt function in readdef.c.

    In the following, we describe the detail of the flow of reading the parameter.
