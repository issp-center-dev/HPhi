Progress Messages

Progress messages are defined in ProgressMessage.h/c. Use these predefined strings for consistent output:

fprintf(stdoutMPI, "%s", cProFinishDefFiles); // "Read definition files."
fprintf(stdoutMPI, "%s", cProFinishDefCheck); // "Check definition files."

Error Messages

Error messages are defined in ErrorMessage.h/c. Examples:

  • cErrNameList : Command line argument error
  • cErrDefFile : Definition file error
  • cErrOutput : Output directory creation error
  • cErrLargeMem : Memory allocation error

Debug Output

For debugging, use conditional output:

#ifdef DEBUG
fprintf(stdoutMPI, "Debug: value = %d\n", value);
#endif

Functions in log.c are used to output the time-stamp. LogMessage.c contains the formats (for print function) of log messages. If we use this format, header-file have to be included as

#include "LogMessage.h"
