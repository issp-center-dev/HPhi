Main driver for TPQ calculation.

Performs NumAve independent TPQ calculations with different random initial states, computing physical quantities at each step.

For each random sample:

  1. Generate random initial state |psi_0>
  2. Repeat for step = 0 to Lanczos_max: a. Apply (l - H/Ns) to |psi> b. Every ExpecInterval steps, compute observables:
    • Energy \(\langle H\rangle\), variance, inverse temperature
    • Green's functions if requested c. Normalize |psi> to prevent overflow

Output files (per sample):

  • SS_rand*.dat: Energy, \(\langle S^2\rangle\), etc. vs step
  • Norm_rand*.dat: Norm vs step (for beta calculation)
  • Flct_rand*.dat: Fluctuations
Parameters
NumAveNumber of random samples to average [in]
ExpecIntervalSteps between observable calculations [in]
XCalculation parameters and results [in,out]
Returns
0 on success, -1 on error
