◆ SectorShiftReason

enum SectorShiftReason

Sector shift (dNe, dNup, dNdown, dTotal2Sz) induced by an excitation operator, used to guard off-diagonal dynamical Green-function input so that the ket A|phi> and bra B|phi> land in the same excited Hilbert sector. valid is FALSE when the (model, operator) excitation is not supported in the current (v1) off-diagonal allow-list.

Why a SectorShift is invalid (for off-diagonal guard diagnostics).
