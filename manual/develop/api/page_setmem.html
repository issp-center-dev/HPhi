Main Allocation Routines

setmem_HEAD()

Allocates BindStruct and basic arrays. Called at program start.

setmem_def()

Allocates DefineList arrays after reading input sizes:

  • Transfer arrays
  • Interaction arrays
  • Site information

setmem_large()

Allocates large wavefunction vectors:

  • v0, v1 : Main vectors (size: idim_max)
  • v1buf : MPI buffer
  • list_1, list_2_1, list_2_2 : Basis lists

This is the largest memory consumer.

Memory Estimation

Total memory scales as:

\[ M \approx 3 \times D \times 16 \text{ bytes} \]

where \(D\) is the Hilbert space dimension. For Hubbard model: \(D = \binom{N_s}{N_\uparrow}\binom{N_s}{N_\downarrow}\)

To set memory, we use ?malloc% function defined in mfmemmory.h, where ? indicates the type of the array and % means the dimension.

For example, char_malloc2(X, N1, N2) function sets the size of memories N1 \( \times \) N2 characters to two dimensional array X.

To set memories to global arrays, we prepare two functions, setmem_def() and setmem_large() functions.

  • setmem_def()

    In this function, the memories of the arrays which do not have large memory are stored.

    Arrays for defining interactions and correlation functions are mainly defined.

  • setmem_large()

    In this function, the memories of the arrays which have large memory are stored.

    Arrays for defining Hamiltonian and vectors are mainly defined.
