Welcome to \({\mathcal H}\Phi\)’s documentation!¶

\({\mathcal H}\Phi\) is a numerical solver package for quantum lattice models based on the exact diagonalization method with parallel computing support. See What is {\mathcal H}\Phi? for details.

Download¶

You can download software and source codes of \({\mathcal H}\Phi\) from GitHub page or release page.
