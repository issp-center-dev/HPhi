#####################################################
Welcome to :math:`{\mathcal H}\Phi`'s documentation!
#####################################################

:math:`{\mathcal H}\Phi` is a numerical solver package for quantum lattice models based on the exact diagonalization method with parallel computing support.
See :ref:`Introduction` for details.

Download
--------

You can download software and source codes of :math:`{\mathcal H}\Phi` from `GitHub page <https://github.com/issp-center-dev/HPhi>`_ or `release page <https://github.com/issp-center-dev/HPhi/releases>`_.
